# TP JavaScript — S4

Travaux pratiques de JavaScript réalisés dans le cadre de l'UE Projet (S4), Licence Informatique, Université de Lille. Le dépôt part d'un template fourni par l'enseignant (structure de base par TP) et contient le travail réalisé pour chaque séance.

## étudiant

- Diallo Alpha Abdoulaye

## Contenu

- `tp1/` — manipulation du DOM : affichage dynamique (mur d'images, liste de pays), gestion d'événements
- `tp2/` — animations sur `canvas` (balle rebondissante, gestion du clavier, obstacles)
- `tp3/` — mini-jeu (panier / œufs) : classes JS (`Rocket`, `Egg`, `Basket`, `Mobile`), boucle de jeu, gestion clavier
- `tp4/` — application React : mur d'images avec détails, conversion de devises
- `tp5/` — application React : panier d'achat (liste d'articles, panier, filtres)

## Environnement technique

JavaScript (ES6+), React, Webpack, Node.js / npm, HTML5 Canvas, Git/GitLab.
